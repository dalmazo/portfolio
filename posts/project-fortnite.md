## Technical UI Designer

**Epic Games**

Two years as Fortnite's Technical UI Designer: rebuilt the battle pass
system on MVVM (from 2 to 8 passes per quarter) and shipped UI for
Jujutsu Kaisen, TMNT, Avatar, and more.

Day-to-day, that meant working closely with other UI Artists to get every
event and pass integrated and production-ready:

- Built and maintained the Widget Blueprints behind these events and
  passes, supporting other UI Artists integrating them
- Authored the custom UI Materials that gave each event and pass its own
  visual identity
- Kept the UI animations running smoothly and optimized the textures
  behind those materials to keep performance in check
- Synced regularly with producers and other teams about risks, listing out
  all the work still ahead and the possible blockers so they could better
  visualize the whole process — I was a strong voice on what was really
  being done and how things were progressing

### Battle pass revamp — from spaghetti code to a reusable system

The old battle pass page was a classic case of a tool used over and over
without ever being revisited: every new pass added its own patch on top of
the last, until the whole thing turned into spaghetti code that was
genuinely painful to maintain.

We rewrote it from scratch using Unreal Engine 5's (relatively new at the
time) MVVM UI framework, giving every pass the same underlying structure
instead of one-off code each time. Epic pushed MVVM as the way forward for
building UI in UE5, and having used it here, I fully agree — it's a great
fit for UI work. That let the team focus on what actually matters — the
player experience — instead of untangling the previous pass's code. The
payoff was significant: fewer bugs, way less maintenance time, and we went
from shipping 2 passes every 3 months to 8 passes in the same window,
opening up a lot more monetization opportunity along the way.
