## Technical UI Designer

Mainly working on engagement events and battle passes. My day-to-day routine
consists of taking care of the Widget Blueprints and Materials for the
Engagement Events and Battle Passes, helping UI Artists integrate and
facilitate all the work into the project.

- Create and give support for Widget Blueprints
- Creating UI Materials to make the UI look awesome
- Identify potential risks for the project and always try to be one step ahead
- Create and maintain UI Animations
- Create optimized textures for UI Materials usage

### New battle pass revamp

We created the new battle pass page from scratch using MVVM. This added the
possibility of reusing the same system for other passes as well.

### Events and passes I was responsible for (Technical UI Design)

- Battle Pass: OG Pass, CH5S1, CH5S2, CH5S3, CH5S4
- Engagement Events: Jujutsu Kaisen, TMNT, Avatar, Pirates of the Caribbean
